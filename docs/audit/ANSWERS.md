## Red Flags Identified During Audit

1. **Raspberry Pi Undervoltage (`hwmon hwmon1: Undervoltage detected!`):**
   * The kernel reports persistent undervoltage throttles. When motors draw current or the LiDAR spins up, the 5V rail dips, risking silent CPU throttling, Wi-Fi drops, and USB disconnects.
2. **LiDAR Power / Response:**
   * `/dev/ttyUSB0` is recognized, but `lidar_reset.py` and direct serial probes returned no data packets until power-cycled. Verify the RPLIDAR motor power lead is not sagging during boot.
3. **Nav2 Costmap Topic Mismatch:**
   * `nav2_params.yaml` directly subscribes to `/scan` rather than the tilt-filtered topic `/scan_filtered`. Running Nav2 without fixing this remap will inject false ground obstacles into the local costmap when traversing ramps.
4. **Pico Firmware Source Missing on Pi:**
   * The Raspberry Pi only contains the compiled USB CDC device; the actual C/MicroPython firmware source for the Pico is not stored in `~/ros2_ws` or `/home/hardleel`.
5. **No Network Clock Synchronization (PTP/Chrony):**
   * If RViz2 or Nav2 nodes are run on the remote laptop, timestamps will drift against the Pi clock, causing TF transform drops (`Lookup would require extrapolation into the past/future`).
